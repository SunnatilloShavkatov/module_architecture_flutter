# l10n.md — Lokalizatsiya (l10n) va Matnlar

> **Etalon ARB:** `packages/core/lib/src/l10n/` (`app_en.arb`, `app_uz.arb`, `app_ru.arb`)
> **Etalon Extension:** `packages/core/lib/src/extension/localizations_extension.dart`
> **Etalon Ishlatilishi:** `modules/auth/lib/src/presentation/login/login_page.dart`
> **Qoida:** Javob o'zbekcha, kod inglizcha (`AGENTS.md` §0).

---

## 1. Joylashuv va Tuzilma

Lokalizatsiya resurslari va kengaytmalar quyidagi tuzilmada joylashadi:

```
packages/core/lib/src/
├── l10n/
│   ├── app_en.arb                    # Inglizcha matnlar (asosiy manba)
│   ├── app_uz.arb                    # O'zbekcha matnlar
│   └── app_ru.arb                    # Ruscha matnlar
└── extension/
    └── localizations_extension.dart  # context.l10n qulay accessor
```

- Konfiguratsiya fayli: `packages/core/l10n.yaml` (loyiha ildizida emas!).
- Generatsiya shu papkadan yurgaziladi: `cd packages/core && flutter gen-l10n`.
- Barcha modullar `context.l10n.<key>` orqali matnlarga ulanadi.

---

## 2. Qat'iy Qoidalar (Non-negotiables)

1. **Hardcoded String Taqiq:** UI ichida foydalanuvchiga ko'rinadigan matnlar qat'iyan hardcoded yozilmaydi (`Text('Sign in')` ❌). Har doim `context.l10n.<key>` orqali olinadi.
2. **Uchala Tilda Bir Xil Kalit:** Yangi matn kaliti qo'shilganda bir vaqtning o'zida har uchala faylga ham (`app_en.arb`, `app_uz.arb`, `app_ru.arb`) kiritilishi shart.
3. **Kalit Nomi Standarti:** Barcha l10n kalitlari `camelCase` formatida va semantik nomlanishi kerak (masalan, `loginTitle`, `notificationEmptyMessage`).
4. **Parametrli Matnlar (Placeholders):** Dinamik qiymatlar (`name`, `count`) string interpolation (`'$text $name'`) bilan emas, ARB placeholders orqali beriladi.
5. **Kesh Generatsiyasi:** Yangi kalit kiritilgandan so'ng kesh yangilanadi (`flutter gen-l10n`).

## 3. Standart Kod Skeletlari va Namunalar

### A. Oddiy Matn Qo'shish

1. `packages/core/lib/src/l10n/app_en.arb`:
```json
"welcomeBack": "Welcome Back"
```

2. `packages/core/lib/src/l10n/app_uz.arb`:
```json
"welcomeBack": "Xush kelibsiz"
```

3. `packages/core/lib/src/l10n/app_ru.arb`:
```json
"welcomeBack": "С возвращением"
```

UI da chaqirish:
```dart
Text(
  context.l10n.welcomeBack,
  style: context.textTheme.headlineMedium?.copyWith(
    color: context.color.textPrimary,
  ),
)
```

---

### B. Parametrli Matnlar (Placeholders)

1. `packages/core/lib/src/l10n/app_en.arb`:
```json
"greetingUser": "Hello, {name}!",
"@greetingUser": {
  "placeholders": {
    "name": {
      "type": "String"
    }
  }
}
```

2. `packages/core/lib/src/l10n/app_uz.arb`:
```json
"greetingUser": "Salom, {name}!"
```

3. `packages/core/lib/src/l10n/app_ru.arb`:
```json
"greetingUser": "Привет, {name}!"
```

UI da chaqirish:
```dart
Text(
  context.l10n.greetingUser(user.name),
  style: context.textTheme.titleMedium,
)
```

---

### C. Raqamli Parametrlar (Count / Plurals)

```json

"@itemsSelected": {

      "type": "int"
    }
  }
```

## 4. Eng Ko'p Qilinadigan Xatolar (Anti-patterns)

### ❌ Anti-pattern 1: UI da to'g'ridan-to'g'ri matn yozish
```dart
// ❌ TAQIQLANGAN: hardcoded string
Text('Enter your email')

// ✅ TO'G'RI:
Text(context.l10n.enterEmailHint)
```

### ❌ Anti-pattern 2: Matnni qo'lda birlashtirish (String Interpolation)
```dart
// ❌ TAQIQLANGAN: grammatik tartib turli tillarda turlicha bo'ladi
Text('${context.l10n.hello} ${user.name}')

// ✅ TO'G'RI: placeholder orqali bitta kalit
Text(context.l10n.greetingUser(user.name))
```

### ❌ Anti-pattern 3: Bitta tilga qo'shib, qolganlarini unutish
```
app_en.arb da yangi kalit bor, lekin app_uz.arb yoki app_ru.arb da yo'q.
Bu l10n generatsiyasida xatolikka olib keladi.
```
