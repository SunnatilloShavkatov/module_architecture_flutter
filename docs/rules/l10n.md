# l10n.md — Lokalizatsiya va Matnlar

> ARB fayllar: `packages/core/lib/src/l10n/` (`app_en.arb`, `app_uz.arb`, `app_ru.arb`)
> Extension: `packages/core/lib/src/extension/localizations_extension.dart`
> Foydalanish: `modules/auth/lib/src/presentation/login/login_page.dart`
> Javob o'zbekcha, kod inglizcha (`AGENTS.md` §0).

## 1. Asosiy qoida

Hech qachon UI ichida foydalanuvchiga ko'rinadigan matnlar hardcoded yozilmaydi (masalan: `Text('Sign in')` ❌).
Har doim `context.l10n.<key>` orqali olinadi:

```dart
Text(context.l10n.loginTitle)
```

## 2. Yangi matn kaliti qo'shish tartibi

Yangi matn qo'shilganda har uchala faylga ham bir vaqtning o'zida kiritiladi:

1. `packages/core/lib/src/l10n/app_en.arb`:
```json
"myNewKey": "My New Text"
```

2. `packages/core/lib/src/l10n/app_uz.arb`:
```json
"myNewKey": "Mening yangi matnim"
```

3. `packages/core/lib/src/l10n/app_ru.arb`:
```json
"myNewKey": "Мой новый текст"
```

Fayllarni saqlagandan so'ng kash generate qilinadi:
```bash
flutter gen-l10n
```

## 3. Parametrli matnlar (Placeholders)

Agar matn parametr qabul qilsa:

```json
"welcomeUser": "Welcome, {name}!",
"@welcomeUser": {
  "placeholders": {
    "name": {
      "type": "String"
    }
  }
}
```

UI da chaqirish:
```dart
Text(context.l10n.welcomeUser('Ali'))
```

## 4. Tekshiruv ro'yxati

- [ ] UI da hardcoded string yo'q, barchasi `context.l10n.<key>` orqali olingan.
- [ ] Yangi kalit `app_en.arb`, `app_uz.arb` va `app_ru.arb` fayllariga to'liq kiritilgan.
- [ ] Kalit nomlari `camelCase` formatida.
